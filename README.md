# kospi-signal-data

코스피 폭락 취약도 계기판(Claude)이 읽는 원본 데이터 저장소입니다. GitHub Actions가 매 영업일 07:20, 19:30(한국시간)에 `collect_official.py`를 실행해 `data/`를 갱신합니다.

이 저장소는 공개 저장소이므로 공개 지표 데이터와 수집 코드만 둡니다. 보유 종목, 점검 결과, 키·비밀번호는 올리지 않습니다.

| 파일 | 내용 | 원 출처 |
|---|---|---|
| data/kospi_index.csv | 코스피 일별 시가·고가·저가·종가·거래량 | 네이버 금융 차트(KRX 지수) |
| data/flows.csv | 코스피 투자자별 순매수(억원), 연기금 포함 | 다음 금융 투자자별 매매동향 API |
| data/fred_*.csv | 원/달러, 브렌트유, 미 10년물, VIX | FRED |
| data/lev_etf.csv | 삼성전자·SK하이닉스 단일종목 레버리지 ETF 시가총액 합계 | 네이버 금융 ETF 목록 |
| data/status.json | 소스별 성공 여부와 마지막 날짜 | — |

투자자별 수급은 2026-10-08에 네이버 금융에서 다음 금융으로 출처를 바꿨습니다. 네이버 투자자별 매매동향 페이지가 2026-09 이후 HTTP 410(제공 중단)을 반환하기 때문입니다. 출처를 바꾸기 전 기간의 수급은 기존에 쌓인 값을 그대로 유지합니다.

인증키나 비밀번호는 쓰지 않습니다. 과거 수급을 더 채우려면 Actions 탭 → Collect KOSPI signal data → Run workflow에서 `backfill_start`에 날짜를 넣어 실행합니다. 다음 금융은 제공 기간이 제한적이어서, 그 이전 날짜는 채워지지 않을 수 있습니다.
